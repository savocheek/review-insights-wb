# Кривая обучения студента на метках учителя

Вопрос: растёт ли качество студента заметно при переходе с 10k к ~17k меткам учителя, то есть есть ли смысл размечать 20k и больше.

- Метки: проход a учителя (Qwen3-14B, промпт v4, без размышлений) — 20,000 валидных ответов из 20k.
- Тест учителя: 2,000 отзывов, отложены по товарам (nmId) — ни один товар теста не попал в обучение; валидация для ранней остановки — ещё 1,000 по товарам. Обучающий пул — 17,000, точки — вложенные подвыборки (5k ⊂ 10k ⊂ всё).
- Студент: ruBert-base из ru-review-sentiment, одинаковый старт для всех точек; головы need + причины (8, multi-label) + тональность (4); до 4 эпох, проверка каждые полэпохи, остановка после 2 проверок без улучшения. Порог need подбирается на валидации, причины — 0.5.
- Метки пользователя: 51 отзывов, need = да у 8 — **очень мало, один отзыв меняет recall на 12 п.п.**; ориентир, не метрика.

| Обучение | need F1 | precision | recall | причины micro-F1 | macro-F1 | тональность acc | need с пользователем: acc / P / R | время, мин | эпох до лучшей |
|---|---|---|---|---|---|---|---|---|---|
| 5,000 | 0.749 | 0.702 | 0.803 | 0.537 | 0.399 | 0.862 | 80% / 43% / 75% | 1.3 | 4.0 |
| 10,000 | 0.766 | 0.724 | 0.814 | 0.653 | 0.557 | 0.867 | 82% / 47% / 88% | 2.3 | 4.0 |
| 17,000 | 0.767 | 0.789 | 0.745 | 0.682 | 0.607 | 0.874 | 84% / 50% / 75% | 3.9 | 3.5 |

## Вывод

**need выходит на плато уже к 10k, причины ещё растут.**

- need F1 против меток учителя: 0.749 (5k) → 0.766 (10k) → 0.767 (17k). С 10k до 17k прироста нет; меняется только баланс precision/recall (порог, подобранный на валидации, 0.2 → 0.6). В тесте 463 отзывов с need = да, разброс F1 при таком размере — около ±0.02, так что 0.766 и 0.767 неразличимы.
- Причины растут заметно: micro-F1 0.537 → 0.653 → 0.682 (+3 п.п. с 10k до 17k), macro-F1 0.399 → 0.557 → 0.607 (+5 п.п.) — прибавляют редкие причины, которым на 10k не хватает примеров.
- Тональность почти не меняется: 0.862 → 0.867 → 0.874.
- С метками пользователя (51 отзыв, need = да у 8 — один отзыв = 12.5 п.п. recall): accuracy need 80% → 82% → 84%, F1 0.55 → 0.61 → 0.60 — в пределах шума.
- Обучение короткое: 1.3 / 2.3 / 3.9 мин на GPU; лучшая точка — в конце (3.5–4 эпохи), т.е. на 5k–10k студент, вероятно, недообучен при лимите 4 эпохи.
- Вывод для объёма: для need 20k меток с запасом; дальнейший рост объёма нужен ради причин (особенно редких), а не ради need. Оговорки: одно зерно, один разрез по товарам; метки учителя — не истина (сверка с пользователем — 51 отзыв).
